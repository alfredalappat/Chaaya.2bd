# Chaaya.2bd
Setup: `npm install` then `npm start` (Node 18+). Open http://localhost:3000
Edit bot messages in `bot.js`. Replace `YOUR-DOMAIN.com` in index.html, robots.txt, sitemap.xml.
Paste your Search Console verification code in index.html (google-site-verification).
Deploy on any Node host with WebSocket support (Render, Railway, VPS) behind HTTPS.
